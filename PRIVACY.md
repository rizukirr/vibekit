# Privacy policy

Last updated: 2026-10-08

## Scope

This policy describes the Vibekit skills-only plugin maintained by rizukirr at https://github.com/rizukirr/vibekit. Vibekit provides workflow instructions for coding agents. The OpenAI submission package contains skills and supporting documents, with no Vibekit-hosted backend, analytics service, or lifecycle hooks.

## Data used during a workflow

Depending on your request and the permissions you grant your coding agent, a Vibekit-guided workflow can involve your prompts, project files, source code, file paths, command output, Git history, and generated plans or reports. These may contain personal information that you provide or that appears in your project.

The coding agent uses this information to carry out the requested design, implementation, debugging, or verification work. The skills-only package does not automatically send this information to the Vibekit maintainer or a separate Vibekit service.

## Coding agents and optional services

Your coding agent provider processes the conversation and any project content or tool results supplied to its service under its own terms, privacy policy, and account settings. Vibekit does not control that provider's storage or retention.

If you authorize an external action, such as pushing a Git branch or creating a GitHub pull request, the selected service receives the content needed for that action. Your agent's enabled tools, permissions, and the service's policies govern that processing. Vibekit does not operate a separate recipient service or automatically sell workflow data to third parties.

## Support and public contributions

If you open an issue, pull request, or discussion in the Vibekit repository, GitHub and the maintainer can access your GitHub identity and the content you choose to submit. Public submissions are visible to other visitors. The maintainer uses them to respond to requests, investigate problems, and maintain the project. Do not include passwords, access tokens, private source code, or sensitive personal information in public submissions.

## Retention

Vibekit does not maintain a separate database of your coding conversations or project content. Generated files, reports, and Git commits remain in your project until you remove them through your local tools. Deleting a working file does not necessarily remove it from Git history or backups.

Your coding agent provider and any external services you use determine their own retention periods. Public GitHub contributions remain available until removed through the platform's controls, subject to GitHub's retention and caching practices. Vibekit does not impose a separate automatic deletion schedule on those contributions.

## Your controls

You can stop using or uninstall Vibekit, restrict your coding agent's file and network access, decline external actions, and remove local artifacts you no longer need. Use your provider's account controls for conversations and data held by that provider. Use GitHub's controls for content you submitted there. For a repository-specific privacy concern, contact the maintainer through the support link below using only the minimum information needed to explain the request.

## Contact and updates

For support or a repository-specific privacy concern, use https://github.com/rizukirr/vibekit/issues. This is a public channel, so do not post sensitive personal information. For security vulnerabilities, follow https://github.com/rizukirr/vibekit/blob/main/SECURITY.md.

Policy changes will be published in this file with an updated date. Review the current policy before using an updated package.
